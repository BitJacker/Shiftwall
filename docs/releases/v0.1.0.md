**Pre-release.** First public version of Shiftwall: migrate FortiGate configurations between models, offline, plus a
sysadmin toolbox. One portable Windows exe, no telemetry.
**Pre-release.** Prima versione pubblica di Shiftwall: migra le configurazioni FortiGate tra modelli diversi, offline,
con una toolbox per sistemisti.

Test it in a lab before any production use. / Provala in laboratorio prima di qualsiasi uso in produzione.

## Highlights

- **Migration wizard** in five steps between FortiGate models running the same FortiOS version: interface mapping,
  header update as in Fortinet's manual procedure, validation, before/after diff, HTML report and checklist.
  Batch conversion with mapping templates.
- **Model database**: 34 models and 96 FortiOS releases (6.2.0 – 8.0.2), every datum with its official Fortinet
  source; unverified data is flagged.
- **Toolbox**: compare, security audit (23 sourced rules), unused objects, export to Excel/CSV, import from CSV,
  IPsec VPN summary, anonymization with an encrypted reversible map, CLI snippets, upgrade planning.
- **Backup from LAN** (optional, off by default) through the FortiOS REST API.
- English and Italian interface, light and dark theme.

## Privacy

Shiftwall sends no data and works completely offline. No telemetry, no automatic updates. `ENC` values are copied
unchanged and never decrypted. / Shiftwall non invia dati e funziona completamente offline.

## Download and verify

1. Download `Shiftwall.exe` and `SHA256SUMS.txt` below (Windows 10/11 x64, portable, no installer).
2. Check the hash: `Get-FileHash .\Shiftwall.exe -Algorithm SHA256` must match `SHA256SUMS.txt`.
3. The exe is not code-signed: SmartScreen shows "Windows protected your PC". After checking the hash, choose
   *More info* → *Run anyway*.

## Known limits

Same FortiOS version required on both units; encrypted or YAML backups are not supported; tested on synthetic
configurations, not yet on real devices. Please report problems with anonymized data only.
