[docs/migration-guide.md](https://github.com/BitJacker/shiftwall/blob/main/docs/migration-guide.md) describes the five wizard steps in a table, without images.

**Task**
1. Run Shiftwall on Windows with the synthetic files in [samples/](https://github.com/BitJacker/shiftwall/tree/main/samples) (steps in the README section "Try it in one minute").
2. Take one screenshot of the Shiftwall window per step (Load, Pre-checks, Mapping, Transform, Report), English UI, light theme, about 1100 px wide. No personal data in paths or other windows.
3. Save them as `assets/screenshots/step-1-load.png` … `step-5-report.png` (PNG, ideally under 200 KB each) and add them under the table in the English section of the guide.

Only the synthetic samples may appear in screenshots.
